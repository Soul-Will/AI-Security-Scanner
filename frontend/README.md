# Frontend - AI Security Scanner

This directory contains the Next.js frontend client for the **AI Security Scanner** project.

Please refer to the main repository [Root README.md](../README.md) for full project documentation, architecture overview, backend setup, environment configuration, and installation guides.

## Quick Start (Frontend Only)

```bash
# Install dependencies
npm install

# Run local development server
npm run dev
```

App runs at `http://localhost:3000`.
Scan dashboard at `http://localhost:3000/scan`.
